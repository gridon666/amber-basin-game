AMBER BASIN — WEBSITE PACKAGE

Весь сайт готов к публикации как статический сайт.

ПУБЛИКАЦИЯ НА NETLIFY:
1. Распакуйте архив amber-basin-site.zip.
2. Откройте https://app.netlify.com/drop
3. Перетащите папку amber-basin-site (не отдельный файл index.html).
4. Дождитесь публикации и откройте выданную ссылку.

Главная страница находится в index.html. Игровая сборка сохранена без изменения в папке game/.
Кнопка «Играть сейчас» загружает game/index.html внутри страницы.
