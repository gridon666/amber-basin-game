AMBER BASIN — GitHub Pages

1. Распакуйте архив.
2. В GitHub Desktop откройте папку amber-basin-site как Local Repository (или замените содержимое уже существующего репозитория этой папкой).
3. Сделайте Commit и Push origin.
4. В GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. Дождитесь публикации и откройте адрес Pages.

Важно: сохраняйте структуру папок. index.html должен лежать в корне репозитория, рядом с папками fonts и game. Не загружайте только index.html.
